# Current art direction: 2D only

Updated 2026-09-08. The active game uses the user's selected rich pixel-art style and elevated tactical perspective. All character, building, terrain and environmental artwork must be 2D. There is no permitted 3D-model fallback or active miniature-production track.

Follow [the current board-art contract](OLYMPUS_BOARD_ART.md), [pixel reference direction](PIXEL_ART_DIRECTION.md), and [delivery handoff](HANDOFF.md). Old Heaven/Hell concepts, rejected commander studies, wooden chess renders and procedural Greek miniatures are historical and have been removed from this project. Their originals remain in the verified shared archive, outside the game checkout.

Use only the built-in image generator authorized by the user. Preserve source sheets and explicit sequence/pivot/masking records. Animation quality is coherent useful motion, not a frame-count quota.
